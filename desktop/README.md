# 옥쌤보드 데스크톱

웹 앱 옥쌤보드를 맥·윈도우 프로그램으로 감싼 것입니다. 수업 창의 **웹 브라우저가 진짜 브라우저**로 열려
네이버·다음·구글 검색 등 모든 사이트를 수업 화면 안에서 쓸 수 있습니다. 내용은 늘 웹 앱 최신판을 씁니다.

- 설치 파일 만들기: GitHub → Actions → **Build desktop app** → Run workflow (또는 `desktop-v*` 태그). 맥(.dmg)·윈도우(.exe)가 Release에 올라갑니다.
- 맥에서 처음 열 때: 애플 개발자 인증서가 없어 "확인되지 않은 개발자" 안내가 나옵니다. 앱을 **오른쪽 클릭 → 열기**, 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.
- 윈도우: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**.
