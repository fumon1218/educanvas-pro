# 우리학교 한눈에 (모바일 웹앱)

나이스 Open API의 학교기본정보, 학사일정, 급식을 조회하는 모바일 우선 정적 웹앱입니다.

## 실행
GitHub Pages 등 정적 호스팅에 `index.html` 과 `manifest.webmanifest`를 같이 올린 뒤, https://open.neis.go.kr 에서 발급한 키를 화면에서 입력하세요.

## 유의사항
정적 브라우저 호출 방식이므로 키가 브라우저 네트워크 기록에 노출될 수 있습니다. 기관 비밀키를 사용하지 마세요. 직접 API 호출은 CORS 허용 여부에 따라 차단될 수 있으므로 실사용 전 확인해야 합니다. 공개 정보 조회용이며 내부 NEIS와 연결되지 않습니다.

이 브랜치는 기존 educanvas-pro 애플리케이션과 분리된 `neis-mobile/` 폴더에만 파일을 추가합니다.
