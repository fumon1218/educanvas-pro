# 옥쌤보드

선생님을 위한 강의용 판서·화이트보드 웹앱입니다.
무한 캔버스 위에 펜으로 판서하고, PDF 수업 자료를 슬라이드로 넣어 그 위에 쓰고, 학생·동료와 실시간으로 함께 그릴 수 있습니다.

## 주요 기능

- **판서 도구**: 펜 6종(기본·연필·만년필·볼펜·점선·형광펜), 지우개, 채우기, 스포이트, 레이저 포인터
- **도형**: 직선, 화살표, 사각형, 원, 타원, 삼각형, 오각형, 글자
- **편집**: 선택, 올가미 선택, 복사·잘라내기·붙여넣기, 그룹, 레이어(잠금·숨기기·순서)
- **슬라이드**: 추가·삭제·이동, 프레젠터 리모컨(PageUp/PageDown) 지원
- **자료 넣기**: 사진, PDF·한글(hwp·hwpx)·워드(docx·doc)·파워포인트(pptx)·엑셀(xlsx·xls·csv)·키노트·페이지스·넘버스(한 슬라이드에 차례대로 / 쪽마다 슬라이드 / 나란히, 쪽 범위 지정), 동영상, 소리, 웹 링크
- **수업 배경**: 모눈, 줄 노트, 원고지, 영어 4선, 오선지, 좌표평면, 칠판 (슬라이드마다 다르게)
- **학생 화면 보내기**: QR·링크로 학생 기기에 읽기 전용 화면, 손들기·O/X·번호 답하기
- **교과서 도구**: 쪽 번호 표시·이동, 영역 확대 사본
- **설치형 앱(PWA)**: 홈 화면·작업 표시줄에 설치, 인터넷이 불안해도 열림
- **웹 브라우저 창**: 유튜브·비메오·구글 문서를 수업 화면 안에서 바로 열기, 유튜브 구간 카드
- **3D 모델(GLB)과 3D 자산함**: 돌려 보기, 애니메이션, 이름표, 지금 모습을 캔버스에 붙이기, 구글 드라이브·폴더에서 가져오기
- **악보**: NWC·NWCTXT·MIDI·MusicXML을 슬라이드로 넣고 악기 소리로 연주, 마디 따라가기, 구간 반복·메트로놈·파트별 소리
- **저장**: 브라우저 자동 저장(30초마다, 변경 시), 다시 열 때 이어서 하기, 수업 파일(.json) 내보내기·열기
- **구글 드라이브 동기화**: '옥쌤보드' 폴더에 자동 저장, 모든 기기에서 같은 수업 목록, 다른 기기 변경 알림
- **내보내기**: 전체 슬라이드 또는 현재 슬라이드를 PDF로
- **함께하기**: 방 코드로 실시간 협업(PeerJS), Google 로그인 공유 링크(Firebase)
- **발표 모드**: 전체 화면, 발표용 도구 막대, 화면 자동 맞춤
- **수업 도구**: 레이저 잔상, 가림막, 스포트라이트, 타이머
- **수업 녹화**: 판서 화면 + 마이크 + 카메라를 한 영상으로, 슬라이드 구간 자동 기록
- **AI 판서 정리**: 주제를 입력하면 판서용 요약을 만들어 줍니다(Gemini, 관리자 설정 필요)

단축키는 앱의 **설정** 창에서 볼 수 있습니다.

## 사용 권한 (허락된 계정만 사용)

옥쌤보드는 **Google 로그인 후, 관리자가 허락한 계정만** 사용할 수 있습니다.

- **관리자:** `fumon1218@gmail.com` (`src/lib/access.ts`의 `ADMIN_EMAIL`, `firestore.rules`의 `isAdmin()`에 같이 적혀 있음)
- **사용 허락하기:** 관리자로 로그인 → **설정 → 사용자 관리** → 상대방의 Google 이메일 입력 → [사용 허락하기]
- **허락 취소:** 같은 화면에서 휴지통 버튼. 다음에 앱을 열 때부터 들어올 수 없습니다.
- 허락받지 않은 계정은 "아직 사용 허락을 받지 않은 계정입니다" 화면과 함께 자기 이메일이 표시되므로, 그 이메일을 관리자에게 알려 주면 됩니다.

> 허용 목록과 공유 보드는 서버(Firebase 보안 규칙)에서도 막혀 있습니다. 다만 GitHub Pages에 공개 배포하면 앱 파일(코드) 자체는 누구나 받아 볼 수 있습니다.

## 배포

`main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다(`.github/workflows/deploy.yml`).
주소는 `https://<GitHub 아이디>.github.io/educanvas-pro/`입니다. 저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 같이 바꿔야 합니다.

### Firebase 설정 (처음 한 번, 필수)

**① 보안 규칙 배포.** 사용 허락 목록과 공유 보드를 지키는 규칙(`firestore.rules`)은 **Firebase에 직접 배포해야 적용됩니다.** 배포하지 않으면 관리자 화면에서 계정을 등록할 수 없습니다.

```bash
npm install -g firebase-tools
firebase login
cd 이 폴더(압축 푼 곳)
firebase deploy --only firestore:rules
```

이 앱은 Firestore의 기본 데이터베이스가 아니라 `ai-studio-75bb…` 데이터베이스를 씁니다. 위 명령은 포함된 `firebase.json`·`.firebaserc` 설정에 따라 그 데이터베이스에 규칙을 적용합니다. 배포 후 Firebase 콘솔 → Firestore → (해당 데이터베이스) → **규칙** 탭에서 `isAllowed` 내용이 보이면 성공입니다.

**② 로그인 허용 도메인 등록.** [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 → **Authentication → 설정 → 승인된 도메인**에 `<GitHub 아이디>.github.io`를 추가해야 배포된 주소에서 Google 로그인이 됩니다.

**③ Google 로그인 사용 설정.** Authentication → 로그인 방법에서 **Google**이 사용 설정되어 있는지 확인합니다.

### AI 기능 (선택)

`.env.local` 파일에 `GEMINI_API_KEY=키값`을 넣으면 개발 중에 AI 판서 정리를 쓸 수 있습니다.
**주의:** 이 키는 빌드 결과(공개 웹페이지)에 그대로 들어갑니다. 공개 배포에는 키를 넣지 말고, 서버(예: Firebase Cloud Functions)를 거쳐 호출하도록 바꾼 뒤 사용하세요.
모델은 `VITE_GEMINI_MODEL`로 바꿀 수 있습니다.

## 알려진 제한

- 동영상은 화면이 열려 있는 동안만 유지됩니다(새로고침 후 다시 넣어야 함). 3MB가 넘는 소리 파일도 마찬가지입니다.
- 협업은 슬라이드 단위로 내용을 통째로 주고받습니다. 두 사람이 **같은 슬라이드에서 동시에** 그리면 나중에 저장된 쪽이 남을 수 있습니다.
- 공유 링크(Firebase)는 슬라이드 하나가 약 900KB를 넘으면 전달되지 않습니다(사진·PDF가 많은 경우). 실시간 협업(방 코드)은 제한이 없습니다.
- 실시간 협업은 공용 PeerJS 서버와 STUN만 사용하므로, 방화벽이 엄격한 학교망에서는 연결이 안 될 수 있습니다.
- 웹 브라우저 창: 일부 사이트(네이버, 구글 검색 등)는 다른 사이트 안에 열리는 것을 막아 두어 빈 화면이 나옵니다. 이때는 [새 탭]으로 여세요. 웹 화면은 브라우저 보안상 녹화 영상에 담기지 않습니다.
- 3D 자산함과 GLB 원본은 이 브라우저에 보관됩니다. 구글 드라이브에서 가져온 모델만 다른 컴퓨터에서 드라이브로 다시 받을 수 있습니다. 3D 이름표는 그 컴퓨터의 자산함에 저장됩니다.
- 구글 드라이브 가져오기는 Google Cloud 프로젝트에서 **Google Drive API**가 사용 설정되어 있어야 합니다(무료). 처음 연결할 때 '확인되지 않은 앱' 안내가 나올 수 있습니다.
- 학생 화면 보내기는 공용 PeerJS 서버(WebRTC)를 쓰므로, 학교 방화벽에 따라 연결되지 않을 수 있습니다. 학생 화면 링크는 로그인 없이 열리므로 코드를 아는 사람만 볼 수 있게 수업 중에만 켜 두세요.
- 악보 연주용 악기 소리는 처음 재생할 때 인터넷(gleitz.github.io 사운드폰트)에서 받아 옵니다.
